# Colors

Everything on this page is read from `src/styles/theme/_colors.css` at build time, so it always
matches the theme. Hover a swatch for its custom property and value.

## Theme tokens

Semantic tokens are `light-dark()` pairs: the `.light` / `.dark` class sets `color-scheme`, which
picks the side. Each swatch shows the light value left and the dark value right; the Themes page
shows them in use.
