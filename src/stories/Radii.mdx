# Radii

`_radii.css` derives every step from one `--radius` base, scaled by a fixed multiplier per step —
so tuning `--radius` re-tunes every step at once.

**Note:** `_colors.css` also declares `--radius: 0` (its shadcn-derived block, alongside a second
`calc(var(--radius) * N)` scale for `sm`/`md`/`lg`/`xl`/`2xl`/`3xl`/`4xl`). Because it's imported
*before* `_radii.css`, its `--radius-*` steps are fully overridden by the ones below wherever both
define the same name — except `2xl`/`3xl`/`4xl`, which `_radii.css` never redefines, so those
three fall through to Tailwind's stock defaults (`1rem`/`1.5rem`/`2rem`) shown in the second
section, unrelated to `--radius` entirely.
