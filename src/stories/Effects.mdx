# Effects

Custom shadow, text-shadow, and aspect-ratio tokens from `_shadows.css`, `_text-shadows.css`, and
`_aspects.css`. Tailwind's stock `shadow-*`/`drop-shadow-*` scale is left untouched and isn't
repeated here.

<div style={{ padding: '3rem 0' }}>
  ## Inset Shadow

  `--inset-shadow-vignette` is the one custom shadow token in `_shadows.css` — a double inset
  shadow using `currentColor`, so it tints with whatever `text-*` color is set on the element.

  <div style={{ paddingTop: '1rem' }}>
    <SpecimenGallery>
      <SpecimenItem title="vignette" subtitle="inset-shadow-vignette">
        <div className="size-32 bg-muted text-foreground inset-shadow-vignette" />
      </SpecimenItem>
    </SpecimenGallery>
  </div>
</div>
