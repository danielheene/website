# Motion

Custom `animate-*` utilities from `_animations.css`, each backed by its own `@keyframes` block.
Tailwind's stock `animate-spin`/`animate-ping`/`animate-pulse` are untouched and not repeated
here. Hover a tile to replay it — `animation-play-state` is toggled on `:hover` for the ones that
run once instead of looping.

  ## Height-driven (slide-up / slide-down)

  `slide-up`/`slide-down` animate `max-height` against a `--slide-height` custom property
  (`1000px` unless overridden) rather than a transform — built for collapsible sections whose
  open height isn't known ahead of time. `max-height` alone won't show a difference against this
  page's fixed-height tile, so these two aren't included as tiles above.
